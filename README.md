# Computer Architecture Project - Logisim CPU

## Overview
This repository contains a Computer Architecture project focused on designing a Central Processing Unit (CPU) using Logisim. It includes the main circuit design, a basic PC (Program Counter) implementation, and a comprehensive project report.

## Files in this Repository
* **`CPU.circ`**: The main circuit file containing the complete CPU design. This file can be opened, viewed, and simulated using Logisim.
* **`BASIC_PC.circ`**: A foundational Program Counter circuit designed as part of the architecture.
* **`CA_REPORT.docx`**: The detailed project report documenting the architecture, design decisions, and workings of the CPU.

## Prerequisites
To view and simulate the `.circ` files, you will need to have [Logisim](http://www.cburch.com/logisim/) installed on your system. (Logisim Evolution is also a good alternative for modern systems).

## How to Run
1. Open Logisim.
2. Go to `File -> Open` and select `CPU.circ` to explore the main processor design.
3. Use the simulation tools in Logisim to test the circuit's behavior and clock cycles.
